# Low Budget GTA

A drive-around game set in Handelu, near Moodabidri, Karnataka. It runs in a phone browser.

Play: https://rameezhandel.github.io/low-budget-gta/

- Ground: Mapbox satellite imagery over Mapbox terrain heights
- Masjid, car and driver: built in Three.js
- Map data © Mapbox © OpenStreetMap
